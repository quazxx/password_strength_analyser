# Password Strength Analyser

Консольное приложение на Python для анализа стойкости паролей.

## Возможности

### Программа анализирует:

-длину пароля
-наличие строчных букв
-наличие заглавных букв
-наличие цифр
-наличие специальных символов
-повторяющиеся символы
-последовательности
-совпадение с распространёнными паролями

На основе этих параметров программа рассчитывает итоговую оценку от 0 до 10 и формирует рекомендации по улучшению пароля.

## Установка

### Клонируйте репозиторий:
git clone https://github.com/quazxx/password_strength_analyser.git, далее 
cd password_strength_analyser

### Создайте виртуальное окружение:
python -m venv .venv

### Активируйте виртуальное окружение.
Windows PowerShell
.venv\Scripts\Activate.ps1

Linux / macOS
source .venv/bin/activate

## Запуск

Основной файл приложения — main.py.

### Запустите программу командой:
python main.py

После запуска программа попросит ввести пароль для анализа.

## Ограничения 

Проект является учебным инструментом. Полученная оценка не гарантирует абсолютную безопасность пароля и не заменяет специализированные системы оценки паролей.
