# Password Strength Analyzer

Консольное приложение для анализа стойкости паролей.

## Возможности

Программа анализирует:

- длину пароля;
- наличие строчных букв;
- наличие заглавных букв;
- наличие цифр;
- наличие специальных символов;
- повторяющиеся символы;
- последовательности;
- совпадение с распространёнными паролями.

На основе этих параметров программа рассчитывает итоговую оценку от 0 до 10 и формирует рекомендации по улучшению пароля.

## Технологии

- Python
- Git
- GitHub

## Запуск

'''bash
python main.py'''

## Внимание

Программа является учебным проектом и не предназначена для определения абсолюной безопасности пароля.
